## Coverage gaps (grepped for, confirmed absent)

- **Insecure TLS**: no `verify=False` and no blocking `requests.*` calls in `vocode/streaming` or `pipecat/src` runtime code (grep empty; Vocode telephony uses async server routes, `telephony/server/base.py:113`).
- **Blocking sleeps in hot paths**: Pipecat has zero `time.sleep` outside the CLI (`cli/commands/init.py:350` only); LiveKit's are confined to CPU monitors (`utils/hw/cpu.py:61,117`) and legacy CLI.
- **Data-layer smells**: no sqlite, no file-per-row, no bash orchestration in any of the four cores (N/A — the classic GLM checklist items 2, 4, 7 simply do not exist here).
- **Fork-bomb shapes**: none; LiveKit process spawns are semaphore-capped (`ipc/proc_pool.py:71` `MAX_CONCURRENT_INITIALIZATIONS`).
- **Hardcoded secrets**: none found via grep in core packages.
- **Security findings**: zero survived with a concrete anchor — the bracketed security category in the findings table is intentionally empty rather than padded.
- **TEN turn-taking**: no in-core endpointing/VAD exists in the Python binding (default no-op `on_cmd`, `async_extension.py:519`); turn logic lives in separately installable extensions outside this scan's scope, so dimension 3 cites the contract, not a missing feature claim.
